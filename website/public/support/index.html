Support

To report a problem or ask a question, open an issue on GitHub. You'll need a free GitHub account. Issues are read by the developer, Sébastien Lavoie, and usually answered within a few days.

Issues are public, so leave out anything personal. To help find the cause quickly, include:

  • Your macOS version (Apple menu › About This Mac).
  • Your LaunchGrid version (About LaunchGrid, in the menu of the menu-bar icon or the Dock icon).
  • What you did, what you expected, and what happened instead. A screenshot often helps.

You can also look through existing issues in case your question has been answered.

Common questions

The shortcut doesn't open LaunchGrid

Another app may already use the same shortcut. Open Settings › General and record a new one; LaunchGrid warns you when a shortcut is taken. You can always open LaunchGrid by clicking its icon in the menu bar or the Dock.

Where are Settings?

Right-click the LaunchGrid icon in the menu bar and choose Settings, or press ⌘ , while the grid is showing.

How do I see all the keyboard shortcuts?

Press ⌘ / while the grid is showing, or choose Keyboard Shortcuts from the ⋯ menu at the top right, from the menu of the menu-bar icon or the Dock icon, or in Settings › General. Typing “shortcuts” in the search finds it too. Esc closes the list. Holding ⌘ for a moment shows the shortcuts that work right now: in a search, in edit mode, with a selection or in an open folder. The menus show each item's shortcut beside it.

An app is missing from the grid

Choose Add Missing Apps from the menu of the menu-bar icon or the Dock icon. It lists installed apps that aren't on the grid, including ones you removed earlier. If the app lives outside your Applications folder, add its folder in Settings › Library, or use Browse to add the app itself.

I removed an app by mistake

Press ⌘ Z to undo, or bring it back with Add Missing Apps. Removing an app from the grid never deletes it from your Mac.

How do I make a folder?

Drag one app onto another and hold it there for a moment. To rename the folder, open it and click its title. A folder disappears when its last app is taken out.

Can I start from my old Launchpad layout?

If your Mac still has the Launchpad database from macOS 15 or earlier, the welcome window offers to import it. You can also import later from Settings › Library. LaunchGrid only reads the database; it never changes it.

How do I move my layout to another Mac?

In Settings › Library, choose Save Grid File. On the other Mac, double-click the saved file, or choose Load Grid File.

How do I run my own script from the App Store version?

The App Store version runs in Apple's App Sandbox, which doesn't let it run shell commands. It can run scripts you put in its Application Scripts folder, the place macOS sets aside for exactly this:

~/Library/Application Scripts/com.sglavoie.launchgrid/

To open it, choose New Action, pick Script, and click Open Scripts Folder. In Finder you can also choose Go › Go to Folder and paste the path above. If the folder isn't there yet, create it.

  1. Write the script, starting with a line that names its interpreter, for example #!/bin/zsh or #!/usr/bin/env python3. AppleScript files (.scpt or .applescript) work too.
  2. Save it in the Application Scripts folder and make it executable: in Terminal, chmod +x ~/Library/Application\ Scripts/com.sglavoie.launchgrid/my-script.sh.
  3. In LaunchGrid, choose New Action, pick Script, and choose it from the list (click the refresh button if it isn't there yet). Add arguments one per line; {query} in an argument is replaced by what you type after the action's keyword in search.

Scripts run on your Mac with your own permissions, outside LaunchGrid's sandbox, so they can do anything you could do in Terminal. In the App Store version macOS runs them for LaunchGrid, so a running script can't be stopped from LaunchGrid. The version downloaded from GitHub runs scripts from the same folder and can also run shell commands directly.

Why does a grid file ask me to check its actions?

A grid file someone gives you can contain actions, and a command in one would run as soon as you pressed Return. So when you load a grid file that has commands, scripts, links to other apps or files that run something when opened, like an app or a script, LaunchGrid lists each of them in full first. Nothing in the file runs while it loads. Keep for Review keeps them, but each one opens in the editor the first time you run it, so you can check what it does; save it there and it runs normally from then on. Remove Them leaves those actions out. Your own layout, which LaunchGrid saves and reads itself, is never checked this way.

When you save a grid file with commands or scripts in your layout, they're left out unless you tick Include commands and scripts; the actions stay in place with their names and icons, to fill in again.

Open at Login is unavailable

macOS only allows this for apps in the Applications folder. Move LaunchGrid there and open it again.

How do I start over?

Choose Rebuild from Scratch in the menu of the menu-bar icon or the Dock icon to lay out your apps again by category or alphabetically. Undo brings back the old layout if you change your mind.

How do I uninstall LaunchGrid?

Quit it from the menu of the menu-bar icon or the Dock icon (or press ⌘Q with the grid open), then move LaunchGrid from your Applications folder to the Trash. To also delete your layout and settings, delete the folders listed in the privacy policy.

Was LaunchGrid made with AI?

Yes. About 99% of its code, and of this website, was written by Claude, Anthropic's AI model, under Sébastien Lavoie's direction. The app itself contains no AI and connects to nothing. The home page explains how it was made.
